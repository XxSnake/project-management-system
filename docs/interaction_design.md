# 项目管理系统 - 交互设计方案 (Single-User Version)

> 注意：本文件是交互构想稿，描述的是理想交互方向。
> 当前已落地页面、接口和限制条件请优先参考 `../src/README.md`、`architecture.md`、`api_reference.md`。

本系统旨在作为您个人的“管理大脑”，简化数据归集与结算过程。重点在于**“外部数据清洗”**与**“自动化结算”**。

## 📂 目录结构
- **src/**: 源代码目录
- **docs/**: 项目文档（需求文档、设计规范及交互方案）
- **contracts/**: 检测合同存放区（支持 PDF、Word、图片，支持自动解析识别）
- **assets/**: 项目资源（图片、图标、样式资源等）

## 1. 核心操作模式

| 模块 | 交互逻辑 | 核心产出 |
| :--- | :--- | :--- |
| **数据收割机** | 复制 WPS 表格内容直接粘贴，或导入 Excel 原始记录。 | 识别人员、项目、检测项数量。 |
| **智能结算配对** | 系统自动根据检测项匹配合同清单，若匹配失败，弹出手动联想选择。 | 确认当日每一笔工作的产值。 |
| **产值看板** | 以人员和月份为维度，一键生成柱状图和明细清单。 | 每个月的人员产值汇总表。 |

## 2. 界面设计建议

### 2.1 “粘贴即录入”工作台
由于您提到员工在 WPS 共享文档填写，最便捷的交互是：
*   **交互逻辑**：您直接全选 WPS 表格中的内容并粘贴到本系统的文本域中。
*   **智能解析**：系统利用简单的文本模型或正则匹配，自动识别出“张三 2026-02-25 在 某某工地 做了 3 组压碎试验”。

### 2.2 “漏检一览”侧边栏
*   在您浏览项目时，右侧常驻一个基于 `标准分类` 库的“核查规则”栏。
*   **交互反馈**：当您录入某个项目进度时，系统会自动划掉该项目在规范中要求的必检项。如果某项一直未被划掉，会保持黄色置顶提醒。

### 2.3 “多单价”辅助选择与合同识别
*   **合同自动化**：将合同文件拖入 `contracts/` 文件夹后，系统自动弹出：“识别到新合同，是否提取清单？”界面。
*   **识别展示**：左侧显示合同原件（PDF/图片），右侧显示识别出的“检测项-单价”列表，您勾选确认后即刻入库。
*   **智能兜底**：当系统识别到没有合同单价的项目时，会在界面下方弹出**“内部指导价”**的快捷气泡。

## 3. 极简视觉风格

*   **集中化管理**：既然只有您一个人用，界面不需要过于华丽，更应偏向 **“工程管理后台”**。
*   **宽屏列表视图**：充分利用显示器宽度，展示合同单价、实际数量、产值计算过程、对应的规范来源等全量信息。
*   **快捷键操作**：支持 Enter 确认、Tab 切换，提升您处理大量数据的速度。
