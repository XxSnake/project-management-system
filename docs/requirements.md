# 工程建设第三方检测项目管理系统 - 需求规格说明书 (PRD)

> 注意：本文件是产品规划文档，不等同于当前代码实现。
> 当前实现状态、目录结构、接口和运行方式请优先参考 `../src/README.md`、`architecture.md`、`api_reference.md`。

## 1. 项目背景与目标
本项目定位为**单人使用的管理工具**。用户（管理员）通过本系统汇总统计工程检测团队的人员产值。系统核心逻辑是：**将每日工作量（源于人工录入或 WPS 共享表导入）与合同/内部单价自动挂钩，生成精确的人员产值统计与项目进度预警。**

## 📂 目录结构
- **src/**: 源代码目录
- **docs/**: 项目文档（需求文档、设计规范、API 文档等）
- **contracts/**: 检测合同存档库（支持 PDF、Word、图片等）
- **assets/**: 项目资源（图片、图标、样式资源等）

## 2. 核心业务流程
- **基础库建立**：建立人员表、项目表、合同清单表（包含单价）。
- **数据源录入**：
    - 方式 A：管理员手动录入员工提交的工作内容。
    - 方式 B：**WPS 共享文档导入/同步**，系统提取关键列数据（人员、项目、检测项、数量）。
- **产值自动计算**：系统根据工作内容匹配合同单价（无合同则使用内部价），计算每日产值。
- **汇总分析**：统计每个人、每个月的总产值，展示项目进度。
- **智能预警**：对比“已做项”与“标准规范项”，提示漏检。

## 3. 功能需求详细说明

### 3.1 智能化文档中心 (Smart Document Center)
- **合同存档库**：新建 `e:\work space\项目管理系统开发\contracts` 目录作为所有合同的汇总地。
- **自动识别与提取 (OCR/Parsing)**：
    - 系统监控此文件夹，当有新的 PDF、Word 或合同图片（PNG/JPG）放入时，自动触发识别。
    - **重点提取项**：合同编号、甲方单位、项目名称、**计费清单（检测项及对应单价）**。
    - **结构化同步**：提取后的单价直接同步至系统的“价目表”中，用于产值自动计算。

### 3.2 数据解析规则 (Data Parsing Rules - Based on WPS)
根据提供的 WPS 工作日志截图，系统需支持解析以下列结构：

| 列 | 字段名 | 解析逻辑 |
| :--- | :--- | :--- |
| **A** | 日期 | 识别 `YYYY/MM/DD` 格式。 |
| **B** | 项目名称 | 全称匹配或模糊匹配项目库。 |
| **C** | 工作/检测内容 | 核心关键词匹配（如：沉降观测、低应变、环境检测等）。 |
| **D** | 数量/单位 | **数值提取**：从“共计 26 点”、“28 根”等文本中提取纯数字及单位。 |
| **E** | 参与人员 | **自动拆分**：识别“、”分隔符，将产值平分或按比例分配给多人（如：赵杰、郑乾、周涛）。 |
| **F** | 备注/部位 | 作为辅助信息记录，不参与产值计算。 |

### 3.3 产值计算公式 (Production Value Formula)
- **单项产值** = `数量 (列 D)` × `合同单价 (或内部单价)`
- **个人日报产值** = `单项产值` / `参与人数 (列 E)`
- **月度产值总计** = Σ `个人日报产值` (按月份筛选)

### 3.4 **核心亮点：标准规范联动预警 (Smart Standards Integration)**
- **规范库关联**：联动 `e:\work space\标准分类` 下的规范文件。
- **逻辑匹配**：根据填写的工程阶段（如：主体施工、装饰装修），自动推导相关规范要求的检测频率和必检项目。
- **防漏检提醒**：
    - 实时比对：已检测项 vs. 规范要求项。
    - 临界报警：若达到检测周期或批次未提交结果，系统在主页推送“漏检预警”。

## 4. 补充建议功能 (Antigravity 建议)

根据行业经验，针对**外检业务**特点，建议加入：
- **4.1 报告出具时效监控**：监控从“原始记录提交”到“正式外检报告出具”的时间，确保符合合同约定的服务周期。
- **4.2 现场端移动记录 (Site Record)**：支持现场录入数据、拍照存证（带经纬度与时间水印），解决外检真实性与实时反馈问题。
- **4.3 外检成本分析**：结合人员日志和路费/住宿等报销费用，分析单个外检项目的盈利能力。
